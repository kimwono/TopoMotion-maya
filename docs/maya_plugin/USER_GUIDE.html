TopoMotion 사용 매뉴얼

설치 → 샘플 선택 → 뼈대 생성 → 재생

사용 환경: Windows · Maya 2027

사용 매뉴얼목차
1. 설치2. 샘플 재생 3. 애니메이션 저장·열기4. 뼈대 저장 5. 패널·버튼 안내6. 검사 7. 문제 해결8. 업데이트·제거

1. 설치

준비 파일　TopoMotion-1.0.2-Windows-Maya2027.zip

  1. ZIP 전체 압축 해제
    설치 후에도 보관할 폴더 선택.
  2. Maya 2027 실행
    작업 중인 씬 저장 → File → New Scene.
  3. 설치 파일 끌어 놓기
    압축을 푼 폴더의 install_topomotion.py를 Maya 중앙 3D 화면으로 끌어 놓기. 실행 확인 창이 뜨면 허용.
  4. 패널 확인
    설치 완료 창 닫기 → TopoMotion → 패널 열기. 패널 그림 보기
  5. [설치 확인] 클릭
    정상 표시: 샘플: 15개 / 복원 검사: 사용 가능.
설치 폴더 이동·삭제 금지. 폴더 안의 파일도 그대로 보관.

매뉴얼 다시 열기: 패널의 [사용 매뉴얼] 또는 설치 폴더의 START_HERE.html.

2. 샘플 재생

  1. ① 샘플 불러오기 클릭.
  2. 목록에서 샘플 선택 → [뼈대 만들기] 클릭.
  3. Windows → Outliner에서 LIB_... 그룹 선택.
  4. 마우스를 3D 화면 위에 놓고 F → 뼈대를 화면 중앙에 표시.
  5. 타임라인의 ▶ 클릭 → 애니메이션 재생.
샘플은 뼈대만 표시. 내 캐릭터에 동작을 자동 적용하는 기능은 없음.
  • 씬 저장: File → Save Scene.
  • 뼈대가 겹칠 때: Outliner에서 이전 LIB_... 그룹 숨기기 또는 삭제.
  • 재생 설정: 샘플을 열면 씬의 FPS와 재생 구간이 해당 샘플에 맞게 변경.
샘플 분류

수중형 · 조류형 · 두발형 · 네발형 · 여섯발형 · 여덟발형 · 뱀형 · 기타
샘플 이름 옆에 관절 개수와 프레임 수 표시.

3. 애니메이션 저장·열기

저장

  1. 애니메이션이 있는 씬 열기 → 저장할 재생 구간 지정.
    예: 1–60프레임.
  2. Outliner에서 루트 조인트 선택.
    루트 조인트: 뼈대 계층의 가장 위 조인트. 메시나 컨트롤러가 아닌 조인트 선택.
  3. [저장 위치 변경] → 보관할 폴더 선택.
  4. ④ 애니메이션 저장 → 캐릭터의 위쪽 방향 확인.
    일반적인 Y-up 씬에서 똑바로 서 있는 캐릭터는 +Y. 방향이 다르면 [다른 방향 선택].
  5. 저장 완료 창에서 anim_이름.json 확인.

다시 열기

  1. ⑤ 애니메이션 열기 클릭.
  2. 저장한 anim_... 파일 선택.
  3. Outliner의 새 TM_... 그룹 선택 → 3D 화면 위에서 F.
  4. 타임라인 ▶ 클릭.
새 뼈대로 생성. 기존 캐릭터는 유지.
재생은 0프레임부터 시작. 예: 저장 구간 1–60 → 재생 구간 0–59.
  • 저장 위치: 패널의 ‘저장 위치’에서 확인. 패널을 다시 열면 기본 폴더로 초기화.
  • 덮어쓰기 주의: 같은 폴더에 같은 리그를 다시 저장하면 기존 파일 교체. 이전 파일을 보관하려면 이름이나 저장 폴더 변경.
  • 저장 대상: 뼈대와 동작. 메시·스킨·컨트롤러는 제외.

4. 뼈대 저장

동작 없이 뼈대 구조만 보관할 때 사용.

  1. 기준으로 삼을 포즈로 이동 → 루트 조인트 선택.
  2. [저장 위치 변경] → 보관할 폴더 선택.
  3. ③ 뼈대 저장 → 위쪽 방향 확인.
  4. 저장 완료 창에서 rig_이름.json 확인.
rig_ 파일은 재생 불가. 동작을 저장하려면 ④ 사용.
위쪽 방향 선택은 정보 기록용. 캐릭터의 자세는 그대로 유지.

5. 패널·버튼 안내

처음 사용: [설치 확인] → [① 샘플 불러오기].

6. 검사 선택 사항

리그 확인

루트 조인트 선택 → ② 뼈대 확인 → ‘뼈대 정보 일치’ 여부 확인.

동작 복원 확인

재생 구간을 32프레임 이상으로 지정 → 루트 조인트 선택 → ⑥ 복원 결과 확인.

  • 검사 구간: 재생 구간의 처음 32프레임.
  • 평균·최대 오차: 원래 동작과 복원한 동작의 회전 차이. 단위는 도(°).
  • 차이가 가장 큰 관절: 평균 차이가 가장 큰 관절.
②⑥은 결과 확인용. 씬이나 애니메이션은 변경되지 않음.

7. 문제 해결

증상조치
설치되지 않음Windows·Maya 2027 확인 → ZIP 전체 압축 해제 → 설치 파일을 3D 화면으로 끌어 놓기.
TopoMotion 메뉴 없음Windows → Settings/Preferences → Plug-in Manager → topomotion_plugin.py의 Loaded·Auto load 체크.
① 사용 불가 / 샘플 없음ZIP 전체를 다시 압축 해제 → 설치 파일 실행.
뼈대가 보이지 않음Outliner에서 LIB_ 또는 TM_ 그룹 선택 → 3D 화면 위에서 F. 화면의 Show → Joints 체크.
뼈대가 움직이지 않음타임라인의 키프레임·재생 구간 확인 → ▶ 클릭.
뼈대가 겹침Outliner에서 이전 LIB_ 또는 TM_ 그룹 숨기기.
조인트 없음 / 한 관절만 검사Outliner에서 뼈대의 가장 위 조인트 선택.
⑤에서 파일이 열리지 않음anim_... 또는 motion_... 파일 선택. rig_ 파일은 재생 불가.
⑥에서 프레임 부족재생 구간을 1–32 등 32프레임 이상으로 지정.
복원 검사 사용 불가Maya 종료 → ZIP 전체를 다시 압축 해제 → 재설치.
저장 실패[저장 위치 변경] → 문서 폴더 등 다른 위치 지정.
이전 버전·다른 위치 관련 오류아래 8절에 따라 기존 설치 제거 → 재설치.
설치 파일 끌어 놓기가 안 될 때
  1. Windows → General Editors → Script Editor 열기.
  2. 아래 입력 영역의 Python 탭 선택.
  3. 아래 두 줄 복사·붙여넣기 → 두 줄 선택 → Ctrl+Enter.
  4. 파일 선택 창에서 install_topomotion.py 선택.
import maya.cmds as cmds, runpy
_tm = cmds.fileDialog2(fileMode=1, caption="install_topomotion.py 선택", fileFilter="Python (*.py)"); runpy.run_path(_tm[0], run_name="__main__") if _tm else None
샘플이 누워 있거나 검사 경고가 뜰 때
  • 위쪽 방향 선택은 기록용. 누운 자세를 자동으로 세우지 않음.
  • ‘빠른 회전 포함’: 빠른 회전이 포함된 구간. 다른 재생 구간으로 재검사.
  • 뼈 길이가 늘어나거나 복잡한 변형이 있는 리그: 원본 씬을 복제한 뒤 확인.

해결되지 않을 때

담당자에게 [설치 확인] 결과, 누른 버튼, 사용한 파일 이름, 오류 화면 전달.

8. 업데이트·제거

제거

  1. 작업 씬 저장.
  2. Windows → Settings/Preferences → Plug-in Manager에서 TopoMotion의 Auto load 해제 → Maya 종료.
  3. 문서/maya/2027/modules/TopoMotion.mod 삭제.
    구버전이 있으면 문서/maya/modules/TopoMotion.mod도 확인. Maya 사용자 폴더를 별도로 지정했다면 해당 폴더에서 확인.
  4. 설치 폴더와 Shelf의 TopoMotion 버튼 삭제.

업데이트·설치 위치 변경

기존 설치 제거 → 새 위치에 ZIP 전체 압축 해제 → 1절에 따라 설치.

작업 파일은 별도 보관. 저장한 Maya 씬과 내보낸 애니메이션 파일은 삭제하지 않기.

다른 사용자에게 전달할 때: ZIP 전체 전달. 동봉된 출처·라이선스 파일 유지.
